# Estia Food Order Terminal App 

Αυτό είναι ένα απλό **τερματικό πρόγραμμα παραγγελίας φαγητού** γραμμένο σε Python. Ο χρήστης μπορεί να δει διαθέσιμα προϊόντα, να προσθέσει/αφαιρέσει είδη από το καλάθι, να δει το σύνολο, και να ολοκληρώσει την πληρωμή είτε με μετρητά είτε με κάρτα.

---

## Λειτουργίες

- Εμφάνιση μενού με διαθέσιμα φαγητά
- Προσθήκη/Αφαίρεση ειδών από το καλάθι
- Προβολή καλαθιού με υπολογισμό κόστους
- Ολοκλήρωση παραγγελίας με επιλογή πληρωμής (μετρητά ή κάρτα)

---
